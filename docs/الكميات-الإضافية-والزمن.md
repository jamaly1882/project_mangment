# الكميات الإضافية، زمن البند، وتعدد المعدات

## 1) تعدد المعدات للبند
- في **تفاصيل البند** صار اختيار المعدات متعددًا (شرائح FilterChip):
  يمكن اختيار معدة رئيسية وأخرى… لكل بند.
- الحفظ يكتب:
  - `equipmentId` / `equipmentName` / `equipmentCode` = **أول معدة** (توافق مع بقية الصفحات والتقارير).
  - `equipmentIds` / `equipmentNames` / `equipmentCodes` / `equipmentWorkUnits` = **كل المعدات**.
  - `equipmentCount` = عدد المعدات.
- لوحة المشرف تعرض «المعدات (n)» بأسمائها مجموعة بفاصل «+».

## 2) استبعاد سطر تكلفة بمربع تأشير
- كل سطر تكلفة (مواد/عمالة/معدات/محروقات) في أعلاه **Checkbox**.
- عند التأشير: يختفي إدخال السطر بالكامل، ولا يدخل في إجمالي القسم، ويُحفظ بحقل
  `excluded: true` — **تختفي الكتابة تلقائيًا ولا يحتاج المستخدم لمسحها بنفسه**.
- عند إزالة التأشير يعود السطر كما كان (البيانات لم تُمحَ من الشاشة).
- السطر المستبعد لا يُدقَّق ولا يُنتج أخطاء حفظ.

## 3) تاريخ بداية البند وانتهائه
- **البداية**: أول يوم يسجّل فيه المشرف كمية منفذة. عند أول إدخال تُكتب
  `executionStartDate` و`contractStartDate`.
- **الانتهاء**: `executionStartDate + durationDays` → `contractEndDate`.
- تظهر في «تفاصيل البند» داخل بطاقة **زمن البند**، وفي بطاقة الكمية في لوحة المشرف.
- التمديد المعتمد يتقدّم على التاريخ المحسوب عبر `timeExtensionUntil`.

## 4) تجاوز الكمية التعاقدية (حد 20%)
- عندما تتجاوز الكمية المنفذة التعاقدية، يُمنع الحفظ ويُنشأ طلب في
  `item_approvals` بالنوع `extra_quantity` (طلب واحد معلّق لكل بند).
- مدير إدارة الجودة يوافق بنسبة **حدها الأقصى 20%** من الكمية التعاقدية.
- الموافقة تُنسخ إلى وثيقة البند:
  `extraQuantityApproved: true` و`extraQuantityPercent`.
- بعد ذلك يستطيع المشرف الإدخال حتى `contractQuantity × (1 + percent/100)`،
  ويظهر له سطر «كمية إضافية معتمدة من مدير الجودة».

## 5) انتهاء زمن البند وتمديده
- إذا تجاوز اليوم `contractEndDate` (أو التمديد المعتمد) يُمنع الإدخال ويُنشأ
  طلب `time_extension`.
- مدير الجودة يوافق بعدد أيام؛ تُكتب `timeExtensionDays` و`timeExtensionUntil`،
  فتُفتح واجهة المشرف من جديد ويظهر «تاريخ انتهاء البند (بعد تمديد)».

## 6) واجهة مدير إدارة الجودة
- لوحة المشاريع فيها **أيقونتان**:
  - **الكميات الإضافية** `add_chart_outlined`
  - **تمديد الوقت** `more_time_outlined`
  - كل أيقونة تُظهر عدد الطلبات المعلّقة.
- صفحة الطلبات: تفاصيل الطلب (تعاقدية/منفذة/النسبة أو الأيام) + زر **موافقة**
  (نافذة رقم بحد أقصى) + زر **رفض**.

## 7) ترتيب واجهة المشرف
1. بيانات البند (ومنها المعدات).
2. **تسجيل الكمية المنفذة** (أولًا كما هو مطلوب).
3. **التكاليف الفعلية** ثم المقارنة والحدود والحفظ.

## المجموعات والحقول
| البيانات | المجموعة / الحقول |
| --- | --- |
| الطلبات | `item_approvals` (`kind`, `status`, `itemId`, `projectId`, `requestedPercent`, `requestedDays`, `approvedPercent`, `approvedDays`) |
| موافقة الكمية | `items/{id}.extraQuantityApproved` + `extraQuantityPercent` |
| موافقة الزمن | `items/{id}.timeExtensionDays` + `timeExtensionUntil` |
| زمن البند | `items/{id}.executionStartDate` + `contractEndDate` |
| المعدات | `items/{id}.equipmentIds` + `equipmentNames` |
