# الكميات الإضافية، زمن البند، وتعدد المعدات

## 1) تعدد المعدات للبند
- في **تفاصيل البند** صار اختيار المعدات متعددًا (شرائح FilterChip):
  يمكن اختيار معدة رئيسية وأخرى… لكل بند.
- الحفظ يكتب:
  - `equipmentId` / `equipmentName` / `equipmentCode` = **أول معدة** (توافق مع بقية الصفحات والتقارير).
  - `equipmentIds` / `equipmentNames` / `equipmentCodes` / `equipmentWorkUnits` = **كل المعدات**.
  - `equipmentCount` = عدد المعدات.
- لوحة المشرف تعرض «المعدات (n)» بأسمائها مجموعة بفاصل «+».

## 2) استبعاد سطر تكلفة بمربع تأشير
- كل سطر تكلفة (مواد/عمالة/معدات/محروقات) في أعلاه **Checkbox**.
- عند التأشير: يختفي إدخال السطر بالكامل، ولا يدخل في إجمالي القسم، ويُحفظ بحقل
  `excluded: true` — **تختفي الكتابة تلقائيًا ولا يحتاج المستخدم لمسحها بنفسه**.
- عند إزالة التأشير يعود السطر كما كان (البيانات لم تُمحَ من الشاشة).
- السطر المستبعد لا يُدقَّق ولا يُنتج أخطاء حفظ.

## 3) تاريخ بداية البند وانتهائه
- **البداية**: أول يوم يسجّل فيه المشرف كمية منفذة. عند أول إدخال تُكتب
  `executionStartDate` و`contractStartDate`.
- **الانتهاء**: `executionStartDate + durationDays` → `contractEndDate`.
- تظهر في «تفاصيل البند» داخل بطاقة **زمن البند**، وفي بطاقة الكمية في لوحة المشرف.
- التمديد المعتمد يتقدّم على التاريخ المحسوب عبر `timeExtensionUntil`.

## 4) الكمية المنفذة والكمية الإضافية (حد 20%)
- **الكمية المنفذة تتراكم**: كل إدخال يُضاف إلى `items/{id}.executedQuantity`
  داخل معاملة (Transaction)، فإدخال 50 ثم 100 يعني **150** لا 100.
- **المقارنة تجري في كل إدخال** مع `contractQuantity` + أي كمية إضافية معتمدة:
  - داخل الحد → يُحفظ فورًا.
  - خارج الحد → **لا تُحفظ الكمية**، وتُفتح نافذة **«كمية إضافية»** تعرض:
    الكمية التعاقدية / الكمية المنفذة / الكمية المدخلة الآن / أقصى كمية
    إضافية مسموحة (20%)، وفيها حقل **«الكمية الإضافية المطلوبة»** بالوحدات
    وحقل **«سبب الطلب»**، ثم زر **إرسال إلى مدير الجودة**.
- الطلب يُخزَّن في `item_approvals` بالنوع `extra_quantity` ومعه الكمية
  المطلوبة `requestedQuantity` وإجماليها `requestedTotal` ونسبتها
  `requestedPercent`، و**طلب معلّق واحد لكل بند** (لا تكرار).
- مدير إدارة الجودة يوافق **بالكمية** (لا بالنسبة)، فتُحوَّل إلى نسبة بحد أقصى
  20%، وتُكتب في وثيقة البند: `extraQuantityApproved` و`extraQuantityPercent`
  و`extraQuantityApprovedQuantity`.
- بعد الموافقة يصبح الحد `contractQuantity × (1 + percent/100)`، ويظهر للمشرف
  سطر «كمية إضافية معتمدة من مدير الجودة».
- أثناء الانتظار تظهر بطاقة **«طلب كمية إضافية قيد المراجعة»**، ويُقفل زر
  الطلب حتى يقرر مدير الجودة.
- زر **«طلب كمية إضافية»** متاح دائمًا في بطاقة البند — حتى بعد اكتمال الكمية —
  فلا يبقى المشرف بلا مخرج عند الحاجة لكمية أخرى.

> **لا فهارس مركّبة:** كل استعلامات `item_approvals` بحقل واحد
> (`itemId` أو `projectId`) والبقية تُفلتر في الذاكرة. سبب ذلك أن جمع فلترين
> أو أكثر (itemId + kind + status) يحتاج فهرسًا مركّبًا في Firestore، وغيابه
> كان يجعل الطلب يفشل بصمت فلا يصل إلى مدير الجودة إطلاقًا. الفهارس مضافة
> احتياطًا في `firestore.indexes.json` لكن الكود لا يحتاجها.

## 5) انتهاء زمن البند وتمديده
- إذا تجاوز اليوم `contractEndDate` (أو التمديد المعتمد) يُمنع الإدخال ويُنشأ
  طلب `time_extension`.
- مدير الجودة يوافق بعدد أيام؛ تُكتب `timeExtensionDays` و`timeExtensionUntil`،
  فتُفتح واجهة المشرف من جديد ويظهر «تاريخ انتهاء البند (بعد تمديد)».

## 6) واجهة مدير إدارة الجودة
- لوحة المشاريع فيها **أيقونتان**:
  - **الكميات الإضافية** `add_chart_outlined`
  - **تمديد الوقت** `more_time_outlined`
  - كل أيقونة تُظهر عدد الطلبات المعلّقة (العدّ يعمل بلا فهارس).
- صفحة الطلبات: تفاصيل الطلب (تعاقدية / منفذة / **الكمية الإضافية المطلوبة
  بالوحدات ونسبتها** / إجمالي المنفذ بعد الموافقة) + زر **موافقة** يطلب
  **الكمية** بحد أقصى 20% + زر **رفض**.

## 7) ترتيب واجهة المشرف
1. بيانات البند (ومنها المعدات).
2. **تسجيل الكمية المنفذة** (أولًا كما هو مطلوب).
3. **التكاليف الفعلية** ثم المقارنة والحدود والحفظ.

## المجموعات والحقول
| البيانات | المجموعة / الحقول |
| --- | --- |
| الطلبات | `item_approvals` (`kind`, `status`, `itemId`, `projectId`, `requestedQuantity`, `requestedTotal`, `requestedPercent`, `requestedDays`, `approvedPercent`, `approvedQuantity`, `approvedDays`) |
| موافقة الكمية | `items/{id}.extraQuantityApproved` + `extraQuantityPercent` + `extraQuantityApprovedQuantity` |
| موافقة الزمن | `items/{id}.timeExtensionDays` + `timeExtensionUntil` |
| زمن البند | `items/{id}.executionStartDate` + `contractEndDate` |
| المعدات | `items/{id}.equipmentIds` + `equipmentNames` |
