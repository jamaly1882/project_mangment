===================================================
تحديث: التكاليف + مشرف البند (بدل السائق)
===================================================

مدير النظام (Admin)
│
├── إضافة محافظة           → governorates
├── إضافة مديرية           → districts
├── إضافة بند              → item_definitions
├── إضافة نوع              → item_definitions/{bnd}/types
├── إضافة مشروع            → projects
│     ├── اسم المشروع + الكود
│     ├── المحافظة + المديرية
│     ├── تاريخ البداية + المدة
│     └── التكاليف (اختياري)
│           ├── materialsCost   تكلفة المواد
│           ├── laborCost       تكلفة أجور العمالة
│           ├── equipmentCost   تكلفة المعدات
│           ├── fuelCost        تكلفة المحروقات
│           └── totalCost       الإجمالي (تلقائي)
├── إضافة مدير للمشروع     → users + projects.managerId
└── إضافة مستخدمين          → users
      ├── مهندس   (engineer)
      └── مشرف بند (supervisor)  ← حلّ محل تبويب السائقين

مدير المشروع (Project Manager) — يدخل باسم المستخدم وكلمة المرور
│
├── لوحة مدير المشروع
│     └── بطاقة «تكاليف المشروع» = تكاليف البنود مقابل مخطط المشروع
│
├── صفحة البنود → إضافة بند
│     ├── 1) تحديد البند (item_definition)
│     ├── 2) تحديد النوع (type)
│     ├── 3) الكود + الكمية التعاقدية + الوحدة
│     ├── 4) المهندس + المعدة + مدة العقد
│     └── حفظ → صفحة تفاصيل البند
│
└── صفحة تفاصيل البند (item_details/{itemId})
      ├── وصف البند + الملاحظات
      ├── تكاليف البند (لكل قسم)
      │     ├── تكلفة الوحدة  →  materialsUnitCost / laborUnitCost / ...
      │     └── الإجمالي المتوقع → materialsCost / laborCost / equipmentCost / fuelCost
      │           (الإجمالي = تكلفة الوحدة × الكمية التعاقدية تلقائيًا،
      │            ويمكن تعديله يدويًا — مع مقارنة بالمتبقي من مخطط المشروع)
      ├── المعدة  → equipmentId
      ├── مشرف البند (بدل السائق) → supervisorId / supervisorName
      ├── نوع الوقود + الكميات المخططة (وقود/زيت/ساعات)
      └── الحفظ يكتب في: item_details + items + item_supervisors/{itemId}

مشرف البند (Supervisor)
│
├── تسجيل الدخول باسم المستخدم → SupervisorPage
├── البنود المسندة إليه من item_supervisors
└── تسجيل الاستهلاك الفعلي → item_details
      consumedFuelQuantity / consumedOilQuantity / executedWorkingHours

ملاحظات تقنية
• الحقول: materials / labor / equipment / fuel في المشروع = إجماليات فقط.
• في البند: تكلفة الوحدة + إجمالي متوقع، ويُحسب executedCost =
  مجموع تكلفة الوحدة × الكمية المنفذة عند إضافة كمية.
• السائق (driver) بقي مدعومًا للقراءة فقط من السجلات القديمة
  item_drivers / item_supervisors يسجّل للمشرفين الجدد.
